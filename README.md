# BLS Platform

> Blue Layer Systems — Production-grade DevOps platform built on Azure

## Overview

A 6-project portfolio platform built with Terraform, GitHub Actions, and Kubernetes.
Demonstrates real-world cloud engineering patterns across infrastructure, security,
observability, and AI integration.

| # | Project | Status | Stack |

| 05 | Platform Engineering | ⏳ Planned | Backstage, Crossplane |
| 06 | AI Gateway | ⏳ Planned | LiteLLM, Azure OpenAI, Ollama |

## Architecture

- **Cloud:** Microsoft Azure (UK South)
- **IaC:** Terraform with remote state
- **CI/CD:** GitHub Actions
- **Security:** Checkov, Defender for Cloud
- **Cost Control:** Infracost, automated shutdown policies
